# OSCrVIDnode.light (Alpha)

[**Download for macOS — Apple Silicon**](https://github.com/Hannes-x-Agent/OSCrVIDnode.light-Alpha/releases/latest/download/OSCrVIDnode-light-Alpha-macOS-Apple-Silicon.zip) · [**Download for Windows — 64-bit**](https://github.com/Hannes-x-Agent/OSCrVIDnode.light-Alpha/releases/latest/download/OSCrVIDnode-light-Alpha-Windows-x64.zip)

A separate video-enabled fork of OSCrnode Light, built with [osc.js](https://github.com/colinbdclark/osc.js/) and Electron. The original OSCrnode Light repository remains the lightweight OSC-only edition.

## What is included

- The complete modular OSC sender: sliders, trigger/toggle buttons, one- and two-point XY pads, custom sends, presets, numeric entry, editable ranges, and float/integer output
- A separate Video tab with a configurable WebGL output canvas
- Checkerboard, calibration test card, solid-colour, text, image, video, and drawing sources
- Independent X/Y tiling and stretch
- Text-overlay compositing
- Multiple named and coloured output markers, including exact edge placement
- A shared composited result for preview, fullscreen preview, PNG capture, and the clean output window
- Connected-display selection and a checkbox that opens a borderless fullscreen output on the chosen display
- Compact responsive video modules with editable titles, drag ordering, collapse, movement lock, parameter lock, and live-control lock
- The same white, black, and bright-red lock language as OSCrnode Light
- Persistent OSC, video, module-order, title, lock, collapse, marker, destination, zoom, and visibility state
- Geist bundled for consistent macOS and Windows rendering

Browser-decodable MP4, WebM, and MOV files are supported. Native HAP decoding is not bundled in this alpha.

## Run from source

```sh
npm install
npm start
```

Then open <http://127.0.0.1:4175>.

## Build desktop apps

```sh
npm run package:mac
npm run package:win
```

Outputs:

- `dist/OSCrVIDnode.light (Alpha)-darwin-arm64/OSCrVIDnode.light (Alpha).app`
- `dist/OSCrVIDnode.light (Alpha)-win32-x64/OSCrVIDnode.light (Alpha).exe`

## Verify

```sh
npm run check
npm run verify
npm run verify:ui
npm run verify:video
```

The Windows package is generated by the tagged-release workflow. It still needs a real-Windows launch test before production use.
